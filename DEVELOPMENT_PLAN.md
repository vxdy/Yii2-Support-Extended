## 4. SQL-алиасы и атрибуты в конструкторе запросов

Статус: первый инкремент реализован в ветке `feature/query-aliases` (`QueryAliases`, `QueryAliasCompletionContributor`); PSI-регрессии проходят, completion в изолированной IDE не проверялся.

- [x] Общий механизм определения доступных алиасов и соответствующих ActiveRecord-моделей на основе YiiModelResolver.
- [x] Учитывать `alias()` основного запроса и `alias()` внутри callback `joinWith()` / `innerJoinWith()`, сокращённую запись `joinWith(['region region'])`, вложенные связи и локальные переменные запросов.
- [x] Определять модель JOIN через объявление связи (`getRegion()` → модель региона), а не по имени алиаса.
- [x] Дополнять алиасы и `alias.attribute` в поддерживаемых аргументах `where`, `andWhere`, `orWhere`, `select`, `orderBy`, `addOrderBy`, `groupBy`, `addGroupBy`, `having` и `andHaving`, учитывая форму выражения.
- [ ] Брать подтверждённые атрибуты из модели/PHPDoc (сделано: `@property` модели и её предков, без свойств-связей); отдельно определить источник схемы для колонок, не описанных в PHP (не сделано). Не выдавать произвольные getter за SQL-колонки и не подключаться автоматически к рабочей БД.
- [x] Разделять области видимости основного запроса, callback и подзапросов; учитывать переопределения и конфликты алиасов. При динамических значениях, ветвлениях и неизвестных Query-методах не угадывать результат.
- [x] Ограничить обход и рекурсию, поддержать отмену и незавершённый PHP-код; не выполнять PHP/SQL для анализа.
- [ ] Добавить регрессии положительных/отрицательных сценариев (сделано, 25 PSI-проверок) и проверить completion в изолированной IDE (не выполнено).
- [ ] Неявный алиас по имени таблицы, `->joinWith()` отдельными операторами над переменной и коррелированные подзапросы не поддержаны.

Критерий приёмки: для `City::find()->alias('city')->joinWith(['region' => function ($query) { $query->alias('region'); }])` во внешнем запросе предлагаются `city` и `region`, после точки — подтверждённые атрибуты соответствующей модели. Алиасы независимых подзапросов не попадают в эти подсказки.

## 5. Подсказки ключей и типов результата asArray()

Статус: запланировано после SQL-алиасов; реализация пока не начата.

- [ ] Отслеживать структуру строки результата ActiveQuery: `asArray()->one()` возвращает массив либо `null`, `asArray()->all()` — коллекцию строк; учитывать `asArray(false)`.
- [ ] Без явного `select` предлагать подтверждённые колонки модели; не включать автоматически getter, виртуальные свойства и незагруженные связи.
- [ ] Учитывать `select`, `addSelect`, `*`, `alias.*`, переименования колонок и выражения с явным алиасом. Для `select(['id', 'name'])` предлагать ключи `id` и `name`, а не все атрибуты модели.
- [ ] Использовать механизм SQL-алиасов для выбранных полей JOIN; различать алиас таблицы и имя ключа результата (`city.id` → `id`, `['cityId' => 'city.id']` → `cityId`).
- [ ] Сохранять структуру строки через локальные переменные, доступ по индексу и `foreach`; учитывать `indexBy()` для ключей внешней коллекции.
- [ ] Разбирать вложенные результаты явно загружаемых связей с учётом `hasOne` / `hasMany`, их `select` и режима массива.
- [ ] Передавать структуру через статически разрешимые возвращаемые значения методов; интеграцию с параметрами `render` и view завершить совместно с этапом Views.
- [ ] Выводить типы значений только при достаточных основаниях с учётом NULL и особенностей PDO; не переносить безусловно приведение типов ActiveRecord на массивы. Не выполнять PHP/SQL и не читать реальные значения из БД ради подсказок.
- [ ] При динамическом `select`, конфликтующих именах колонок и неоднозначном потоке данных сохранять только достоверную информацию; поддержать отмену, ограничения обхода и незавершённый код.
- [ ] Добавить регрессии для `one`, `all`, `foreach`, выбранных/переименованных полей, JOIN, `indexBy`, связей и неизвестных выражений; проверить completion в изолированной IDE.

Критерий приёмки: в `$city['…']` после `City::find()->asArray()->one()` предлагаются известные колонки City с учётом возможного `null`; после `select(['id', 'name'])` — только выбранные ключи. После `all()` те же ключи доступны в `$cities[0]['…']` и в переменной строки внутри `foreach ($cities as $city)`. Для переименованных колонок предлагаются имена результата, например `cityId`.
